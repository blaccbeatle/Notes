POSTPARTUM PSYCHOSIS: FEATURES

Postpartum psychosis
   │
   ├─ Psychiatric emergency
   ├─ Onset: ~1–2 weeks (variable)
   ├─ Confusion: present
   ├─ Hallucinations/delusions: present
   │     └─ e.g., 1st-person auditory
   └─ Suicide risk: very high
---
Confusion/hallucinations present?
   │
   └─ Yes ─► Blues ruled out



POSTPARTUM MENTAL HEALTH: BLUES VS DEPRESSION VS PSYCHOSIS

Feature comparison
   │
   ├─ Blues
   │     ├─ Onset: first few days
   │     ├─ Course: self-limiting
   │     ├─ Confusion: none
   │     ├─ Hallucinations/delusions: none
   │     ├─ Suicide risk: none
   │     └─ Normal adjustment reaction, not psychiatric
   │
   ├─ Depression
   │     ├─ Low mood >2 weeks
   │     ├─ Confusion: none
   │     ├─ Hallucinations/delusions: none
   │     └─ Psychiatric
   │
   └─ Psychosis
         ├─ Onset: ~1–2 weeks (variable)
         ├─ Confusion: present
         ├─ Hallucinations/delusions: present
         │     └─ e.g., 1st-person auditory
         ├─ Suicide risk: very high
         └─ Psychiatric emergency

MANAGEMENT OF POSTPARTUM PSYCHOSIS

High suicide/homicide risk?
   │
   └─ Yes ─► Immediate hospital admission
                │
                └─ + 1:1 observation
---
Severe case?
   │
   └─ Yes ─► Temporary mother-child separation
                │
                ▼
             Newborn effect: mother unable to feed
                │
                ▼
             Risk of dehydration
                │

                └─ Hypoglycaemia
                │
                ▼
             If separated: educate father on formula feeding
